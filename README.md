# 💳 Credit Card Key Facts Statement — HTML/CSS Page

A front-end practice project that builds a bilingual (**English / Arabic**) **Key Facts Statement (KFS)** page for a credit card product, based on the ADCB credit card KFS layout.

> This is a personal UI practice project and is not an official ADCB website.

---

## ✨ Features

- Bilingual layout with English and right-to-left Arabic text
- Structured sections for key terms, fees, charges and important notes
- Clean, print-friendly document styling
- Responsive design

## 🛠️ Tech stack

HTML5 · CSS3 · Bootstrap · Google Fonts

## 🗂️ Files

```
adcb/
  index.html
  style.css
```

## 🚀 How to use

No install or build step is needed.

```bash
git clone https://github.com/nawfil03/ADCB-Credit-card.git
cd ADCB-Credit-card
```

Open **`adcb/index.html`** in your browser, or serve the folder locally:

```bash
npx serve .
# or
python -m http.server 8000
```

Then visit http://localhost:8000 and open `adcb/index.html`.
